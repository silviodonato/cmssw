Geometry and data scope

Only channels with digis in the selected event are drawn. Every exported DetId is checked against the D128 topology. The reported positions are reconstructed cell centres of gravity in global centimetres. Display polygons use CMSSW's nominal cell centres and orientation, with the correct high-/low-density pitch. They are drawn at full nominal size, so neighbouring cells tile without gaps; polygon edges are a display aid, not exact partial-sensor boundaries. Sample 2 is the in-time sample. ADC-mode cells are colored by the raw sample data count (linear scale, set per layer/endcap/sample); TOT-mode values are shown separately, not mislabeled as ADC. All samples are available in the selector. Layer and endcap selectors change the displayed slice; the complete selected dataset is embedded in this one file. No server or internet connection is required.
